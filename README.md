# Week_2-Tasks
This week focuses on fundamental image-processing techniques using Python and OpenCV.

The task includes implementing different image filtering methods, thresholding techniques, and morphological operations to understand how images can be enhanced, denoised, segmented, and processed.

## Prerequisites

Make sure Python is installed on your system.

Place all the Python files and required input images in the project folder.

## Required Libraries

The programs in this task use the following Python libraries:

- OpenCV
- NumPy

Install the required Libraries:
``` bash
  pip install opencv-python 
  pip install numpy
```
